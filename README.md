# Petits Jeux – old iPad kids games

Six very simple games for a 2–3 year old, built to run on an iPad 3 (iOS 9.3) in Safari:
animals, bubbles, finger painting, peekaboo, rainbow piano and memory. Spoken in French, English, German or Russian.

Live: https://bereffy.github.io/old-iPad-kids-game/
