# Petits Jeux – old iPad kids games

Six simple games for a 2–3 year old, built to run on an iPad 3 (iOS 9.3) in Safari, in French, English, German or Russian.

| Game | Levels |
|---|---|
| Animals | Listen · Find among 3 · Find among 6 |
| Bubbles | Slow · Fast (with hidden animals) · Colours |
| Painting | Brush · Rainbow · Stamps |
| Peekaboo | 1, 2 or 3 blankets |
| Piano | Free · Magic piano · Follow the light |
| Memory | 4, 6, 8 or 12 cards |

Each game has a level picker, restart button, a "how to play" sheet (can be read aloud) and stars to win.

Live: https://bereffy.github.io/old-iPad-kids-game/

Code is plain ES5 (no modern JavaScript) so it runs on Safari 9.
